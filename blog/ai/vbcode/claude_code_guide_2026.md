#### 1. 新安装先使用 `/statusline` 配置一下终端，这个是使用 Claude Code 看过最多的地方
#### 2. 2026 年底了，不要瞎装 code skill，现在 Claude 模型的 Agent 能力已经足够了
#### 3. 善用 `/simplify`，减少屎山
#### 4. 与其用 `/compact`，还不如让它吐一个简短的压缩文档，新开窗口读取这个
#### 5. 重要的会话窗口及时 `/rename`，另外 Claude Code 本地会话记录默认保存 30 天，需要注意
#### 6. 能截图给他看，就不要拿嘴描述
#### 7. 及时更新新版本，`claude upgrade`
