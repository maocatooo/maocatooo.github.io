# CSV Document Parsing - CSV文件博客写作助手

本技能帮助将 CSV 文件中的碎片知识转化为结构良好的博客文章，通过结合项目中现有的 markdown 文档来丰富内容。

## 目的

- 读取根目录下包含用户近期获取的碎片知识的 CSV 文件
- 分析项目中现有的 `.md` 文件以了解当前文档结构
- **优先更新现有文章**: 如果找到相关内容，优先更新现有文章
- **创建新的博客文章**: 只有在没有相关内容时才创建新文章
- 生成格式正确的 markdown 文件（包含 front matter）

## 工作流程

### 1. 发现 CSV 文件

```bash
# 查找根目录下的所有 CSV 文件
ls *.csv
```

### 2. 解析 CSV 内容

读取并分析 CSV 结构。

```bash
cat *.csv
```

预期格式：
```csv
date,content
2024-01-15,content
```

常见列：
- `date`: 知识获取的日期
- `content`: 碎片知识内容

### 3. 分析现有文档

```bash
# 查找所有 markdown 文件
find . -name "*.md" -not -path "*/node_modules/*" -not -path "*/.git/*"
```

需要检查的关键目录：
- `/blog/` - 现有博客文章
- `/golang/`, `/Python/`, `/中间件/` - 主题特定文档
- 查看 `SUMMARY.md` 了解当前结构

### 4. 匹配和合并内容

对于每个 CSV 条目：

1. **搜索相关的现有内容**
   - 使用 `grep_search` 在现有 `.md` 文件中查找相关主题
   - 检查是否已存在该主题的博客文章

2. **决定：更新或创建（优先更新）**
   - **更新现有的**: 如果找到了相关内容（**优先选择**）
   - **创建新的**: 只有没有找到相关内容时才创建

3. **生成/更新内容**
   - 将碎片知识与现有文档结合
   - 添加适当的 front matter（标题、日期、标签）
   - 确保与现有博客文章格式一致

### 5. 生成博客文章结构

标准博客文章格式：

```markdown
---
title: [描述性标题]
date: YYYY-MM-DD
tags: [tag1, tag2, tag3]
---

[可选的副标题或介绍]

## 背景/上下文

[为什么这个主题很重要]

## 核心内容

[来自 CSV 的主要知识点，展开并组织]

## 示例/代码

[如果适用，使用正确的代码块]

## 最佳实践/技巧

[实用建议]

## 参考资料

[相关链接到文档]
```

### 6. 更新 SUMMARY.md

创建/更新博客文章后：

1. 在适当的位置将新条目添加到 `SUMMARY.md`
2. 保持层次结构
3. 确保链接格式正确

## 输出位置

- 新博客文章：`/blog/{category}/{topic}.md`
- 文档更新：更新主题目录中的相关文件
- 摘要更新：`/SUMMARY.md`

## 质量检查

完成前检查：

1. **Front matter**: 确保有正确的 YAML front matter（标题、日期、标签）
2. **格式**: 与现有博客文章一致
3. **链接**: 所有内部链接有效
4. **代码块**: 使用正确的语言标识符格式化
5. **标签**: 符合现有标签约定
6. **摘要**: 已更新新/修改的条目


## 反模式

- **不要** 优先创建新文件 - 始终先检查是否可以更新现有文件
- **不要** 创建重复内容 - 始终先检查现有文件
- **不要** 忽略现有结构 - 遵循 `SUMMARY.md` 组织
- **不要** 创建过大的文件 - 如需要拆分成逻辑主题
- **不要** 忘记 front matter - 所有博客文章都需要正确的元数据
- **不要** 修改 node_modules 或构建产物

## 成功标准

1. 所有 CSV 条目都已处理
2. **优先更新现有文件**: 已检查并更新相关现有文章
3. 新内容已正确整合到现有文档中
4. 博客文章遵循项目约定（front matter、格式、标签）
5. `SUMMARY.md` 已更新新条目

## 使用的工具

- `read_file`: 读取 CSV 和现有 markdown 文件
- `glob`: 查找项目中的 markdown 文件
- `grep_search`: 搜索相关内容
- `write_file`: 创建新的博客文章
- `edit`: 更新现有文件
